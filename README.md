# FujiStudio (iOS)

Custom local RAW/DNG metadata & profile conversion tool for iOS (`arm64`), packaged as an unsigned `.ipa` for personal installation via Sideloadly.

## Build via GitHub Actions

1. Open the **Actions** tab and select **Build FujiStudio iOS IPA**.
2. Once the workflow completes, download the **`fujistudio-ios-ipa`** artifact.
3. Extract `FujiStudio-iOS.ipa` and install using **Sideloadly**.
